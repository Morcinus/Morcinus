# Hi there! 👋

I'm Jan Jeníček, a software engineer based in Prague, Czech Republic.

I've been building software for over 10 years, ranging from mobile games and personalized learning algorithms to production-ready web applications.

My current side project is [Eduriam](https://eduriam.com/), an educational platform aimed at helping students and aspiring software engineers learn and master their craft.

My main tech stack is **.NET, Node.js, TypeScript and Next.js**. Over the years, I've worked on both frontend and backend development, with a primary focus on backend engineering.

Here on GitHub, you'll find a few of my open-source projects. Most of my work takes place in private repositories, but you can explore more of what I've built in my [project portfolio](https://janjenicek.cz/).

### Fun facts

- 🎮 In high school, I led the development of a Christmas-themed mobile game called [Gift Rush: Unnoticed](https://janjenicek.cz/), which we released on Google Play. Our classmates spent most of December playing it instead of paying attention in class. As it happens, the game's source code was also included in the [GitHub Arctic Code Vault](https://archiveprogram.github.com/arctic-vault/), where it's now preserved on archival film 250 meters deep in the Arctic permafrost, designed to last for at least 1,000 years.
- 🎓 During university, I built the first version of Eduriam, featuring highly optimized learning and spaced repetition algorithms that helped my friends and me earn our engineering degrees and graduate with honors.
